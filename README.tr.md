[English](README.md) | Türkçe

Çoğunlukla **Java / Spring Boot** ve **Python / FastAPI** ile çalışan bir backend geliştiricisiyim.
Okunması kolay, iyi test edilmiş ve güvenle değiştirilebilen servisler yazmayı seviyorum.

**Kullandığım teknolojiler**

- **Backend:** Java 21, Spring Boot, Spring Security (JWT), Hibernate / Envers, Python, FastAPI, SQLAlchemy
- **Veri:** PostgreSQL, Flyway, Alembic, Redis, Hazelcast
- **Frontend:** React, Expo (React Native)
- **Araçlar:** Docker, GitHub Actions, JUnit, pytest
